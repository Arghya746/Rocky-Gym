A modern, responsive gym website and management system demo designed for fitness centers and gym owners.

## ✨ Features

### 🏠 Gym Website
- Modern premium gym landing page
- Responsive design
- Dark / Light mode
- Fitness athlete hero section
- Animated sections and hover effects
- Membership pricing cards
- Testimonials
- Contact / Free Trial form

### 📊 Gym Management Dashboard
- Admin dashboard
- Active member statistics
- Daily attendance tracking
- Member management
- Workout management
- Payment ledger
- Membership expiry tracking
- Interactive dashboard navigation

### 💳 Membership Plans
- Monthly membership
- 6-month membership
- Annual membership
- Interactive plan selection
